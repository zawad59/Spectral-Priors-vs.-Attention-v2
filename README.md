# Spectral-Priors-vs.-Attention-v2
This is our code base for Spectral Priors vs Attention: Investigating the Utility of Attention Mechanisms in EEG-Based Diagnosis paper. All the pre-processing scripts, ML Baselines, KL Divergence, CRT Ablation, Conversion of Tensors, Transformer Models' data loading, data factory changes are uploaded to their respective folders.


**Original Datasets:** [ADFTD](https://openneuro.org/datasets/ds004504/versions/1.0.6/), [APAVA](https://osf.io/jbysn/overview/), [TDBrain](https://brainclinics.com/resources/), [AMP-SCZ](https://nda.nih.gov/ampscz)
 

Traverse to each dataset folder and run their spectral feature extraction (FFT DWT) script by downloading the original dataset folder and filtering subjects as mentioned in the paper. Upon Spectral Feature Computation, the stratified split generation script would generate the 5 splits with train-val-test subjects. Then passing the stratified_holdout_directory as the model param for LDA/RDA would start the train-test process of ML models. The data loader script for Transformer models **script:** `Transformer_Changes/data_provider/data_loader.py` has been modified for the AMP-SCZ and TDBrain class.

Along with [Medformer]([url](https://github.com/DL4mHealth/Medformer)) and [Reformer](https://github.com/google/trax/tree/master/trax/models/reformer), [TeCh](https://github.com/Levi-Ackman/TeCh) we have integrated [EEG-Conformer](https://github.com/eeyhsong/EEG-Conformer) model for our evaluation on the rest-EEG datasets. AMP-SCZ Loader class and data dictionary is updated in the **script:** `Transformer_Changes/data_provider/data_factory.py.  For evaluating Conformer models' performances on the AMP-SCZ dataset, the following configuration was used:

`python -u run.py --task_name classification --is_training 1 --root_path ./dataset/AMP-SCZ --model_id AMP-SCZ_Conformer --model Conformer --data AMP-SCZ --e_layers 6 --batch_size 32 --d_model 128 --d_ff 256 --swa --des 'Exp' --itr 5 --learning_rate 0.0001 --train_epochs 100 --patience 10 --use_gpu True --dropout 0.15 --weight_decay 1e-2`

**Transformer-Evaluation and Utils:** For evaluation of Transformer models, the `--is_training` param should be set to 0 keeping the same params used for training. For generating the attention scores, `--output_attention` param should be included with other input params. Attention map computations are performed in the `exp/exp_classification.py` and `utils/vis_attn.py`.

**KL-Divergence Analysis of Medformer:** We extract the window-averaged, last-layer, all-head query-key attention matrix for each subject, and compute the KL divergence independently for every (head, query) row between all correct-incorrect subject pairs within each split. After removing the CLS key, the attention matrix size is 64×64 for ADFTD and APAVA, and 32×32 for TDBrain and AMP-SCZ, reflecting `Medformer's` dataset-specific seq_len, enc_in, and patch_len configurations. We obtain these matrices by running the Medformer evaluation script and passing `output_attention` as a param.

For the KL-Divergence scores in table 2 of the paper, the same configuration of Medformer model was run with dataset specific params as laid out in the `scripts/Medformer.sh` file. For ADHD, we use the basic configuration provided in their repo. The `--output_attention` generates folders like `ADHD_Medformer_RAW_ATTN_Sc` where we have correct and incorrect attention weights for query and key vectors for 64 patches. It generates two csvs for correct predictions and incorrect predictions. We run the `KL_raw_pairs.py` on those two csvs resulting in `kl_raw_by_head_query_pairs.csv`. Finally, we compute the mean and standard deviation for all correct and incorrect pairs by running the `Calc_Grand_Mean_KL_raw.py` script.

**CRT Ablation:** For ablating the Cross-token interaction, we keep our changes limited to `models/Transformer.py` in it's constructor and classification method where masking is applied to the off-diagonal attention weights. 

**Sensitivity of Spectral Features:** To reproduce the results of section 3.3 with the Medformer model, run the **script:** `Common/increase_Tensor_Dim_SBD` with param `--flatten` with the `Feature` numpy directory downloaded. When a dataset feature directory is provided as input, the script would segregate the time-signals representing 5 frequency bands which would generate a modified tensor dimension. For Random Bands run the `Common/increase_Tensor_Dim_RBD`. We modify and upload the `data_provider/uea.py`, `layers/augmentation.py` and `layers/embed.py` for dimension handling of updated tensors. The `data_provider/data_loader.py` needs to be changed for attention models before running the `SBD-RBD` decomposition experiments.

For Appendix Results traverse to `Timing_Analysis/Spectral_Pipeline/{dataset}/` and run `timing.py` with required params -- that would generate the whole spectral pipeline with distributional statistics of number of windows per subject across datasets. For Within group KL-Div results: keep the csvs for correct-incorrect predictions of attention weights and run `kl_within_group.py` and `Calc_within_group_stat.py`. To generate the distribution from uniform KL: run `Div_from_Uniform.py`.
